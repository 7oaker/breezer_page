# breezer.now
#
# Two kinds of automated visitor matter here and they are listed separately on
# purpose, because they are different decisions.
#
# 1. Answer and agent crawlers. These are how the site gets cited in AI answers
#    and how an agent reads it when a person asks one to look something up.
#    Blocking them removes the site from that surface entirely. All allowed.
# 2. Training crawlers. These take content to train models and do not send
#    traffic or citations back. Allowed here as well, because a quit-nicotine
#    page is more useful inside a model than outside one, but this is the group
#    to change if that judgement ever changes.
#
# Nothing on this site is gated, so there is no crawl-budget reason to narrow
# any of it.

User-agent: *
Allow: /
